This is the first post on the site. Posts live in `_posts/` as Markdown
files named `YYYY-MM-DD-title.md`, and Jekyll turns them into pages
automatically — no build config needed beyond what's already here.

You can use all standard Markdown, including code blocks:

```bash
bundle exec jekyll serve
```

and it will be syntax-highlighted automatically.
